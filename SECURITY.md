# Sicherheit

## Lücke melden

Bitte melde Sicherheitslücken **nicht** öffentlich als Issue. Nutze stattdessen die Funktion „Private vulnerability reporting“ von GitHub:

1. Im Repository auf den Reiter **Security** gehen.
2. **Report a vulnerability** wählen.
3. Beschreiben, was passiert, wie es sich nachstellen lässt und welche Version (`vX.Y.Z (sha)` im Hinweis der App) betroffen ist.

Wir melden uns so bald wie möglich und veröffentlichen eine Korrektur als neues Release.

## Unterstützte Versionen

Nur das jeweils neueste Release erhält Korrekturen.

## Was µEBS bewusst nicht schützt

Die Daten liegen unverschlüsselt im Browser, und der PIN ist nur ein Bedienschutz. Details in [docs/datensicherheit.md](docs/datensicherheit.md).
